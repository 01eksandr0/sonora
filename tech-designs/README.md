# Sonora — Technical Designs

Ця папка містить архітектурні та технічні дизайни (Tech Designs) для задач проекту Sonora згідно з [ROADMAP.md](../ROADMAP.md).

## Конвенція найменування

- Файли: `tech-design-{номер_задачі}.md` (наприклад, `tech-design-15.md` або `tech-design-03.md`).
- Гілки: `tech-design-{номер_задачі}`.

## Структура техдизайну

Кожен техдизайн створюється за допомогою скіла `tech-design` і описує:

1. **Контекст і цілі** (зв'язок із розділом ROADMAP.md).
2. **Зміни в базі даних** (Prisma schema, індекси, міграції).
3. **Бекенд реалізація** (NestJS модулі, ендпоінти, сервіси, DTO, Redis кеш, безпека).
4. **Фронтенд реалізація** (FSD шари, сторінки, віджети, Pinia, TanStack Query, UI/UX).
5. **Спільні контракти** (`packages/shared-types`, `packages/api-client`).
6. **План впровадження** (чек-лист підзадач).
7. **Definition of Done** (критерії якості та тести).
