# Sonora — Task Reviews

Ця папка містить збережені звіти авторев'ю коду (Auto-Reviews) для задач згідно з [ROADMAP.md](../ROADMAP.md).

## Конвенція найменування

- Файли: `task-{номер_задачі}-review.md` (наприклад, `task-15-review.md`).
- Гілки, що рев'юються: `task-{номер_задачі}`.

## Рівні критичності зауважень

1. 🔴 **Критично (Critical)** — блокуючі дефекти безпеки, втрати даних, поломки збірки.
2. 🟠 **Потрібно виправити (Must fix)** — логічні баги, граничні випадки, порушення архітектури FSD/NestJS.
3. 🟡 **Можна виправити в майбутньому (Should fix / Tech debt)** — оптимізація запитів, винесення дублювання, покращення типів.
4. 🟢 **Не критично / Рекомендації (Nit / Suggestions)** — мінорні зауваження до стилю та неймінгу.
